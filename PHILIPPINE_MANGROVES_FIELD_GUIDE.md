## Overview

This guide catalogs the **36 true mangrove species across 17 genera and 12 botanical families** documented in Philippine coastal and estuarine wetlands. It serves as the authoritative reference for BakaWatch's species catalog, seedling inventory, restoration zonation, and machine learning image datasets.

## Integration in BakaWatch

- **Database Reference Catalog (`coastalwatch-api`)**: Seeded into `mangrove_species` table via `MangroveSpeciesSeeder.php`, accessible via `GET /api/species` and `GET /api/reference/monitoring`.
- **Frontend Zonation & Habitats (`coastalwatch-frontend`)**: Mapped in `lib/mangrove-zonation.ts` to guide proper planting, survival rates, and inventory records.
- **ML Classifier Service (`ml-service`)**: Metadata indexed in `main.py` (`SPECIES_INFO`), with image collection pipeline in `download_dataset.py` support for research-grade fine-tuning across all 36 species.
